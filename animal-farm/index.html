Animal Farm

VR Musical Expression Game

Overview

To explore the potential of NIME (new interface for musical expression) in VR, we created an environmental instrument that the user can make their beats by picking animals while traveling around. We themed it around a farm and farm animals.

My Contribution

Game mechanic development, animation design, environment design, interaction Design, UI design. I prototyped these stuff in Unity, did game testing, and iterate details.

Timeline & Status

Nov. 2022 (2 weeks)

Tool

Figma, Unity, Github, Blender, Visual Studio, Ableton Live

Team

Sin-yu Deng, Alexa, Earl Bae, Zelda Hu

DESIGN BREAK DOWN

How it work?

In the environment, we placed various animals around for the user to interact with. There are eight animals, including turkey, horse, sheep, pig, dog, bird, cow, and llama, and each animal makes a unique noise. If the user catches an animal, it will generate a noise and start following the user to wander around.

Mechanics of Music Composition

Users can create 2 tracks in total, each with 8 beats in the game. Every time they catch one animal, they add one beat t the track. The sound will start looping once it is added to the track. When the user fills all the beats by catching animals, the game ends.


8 beats and 2 tracks are the simplest and most common rhythm we can think of. We want to make the mechanics as easy as we can to allow the majority of players to express their creativity and enjoy the process of composing their music.

Environment Design & UI Design

The game adopts a cute and relaxing farm visual style and vibe.


I created multiple different places in the environment so that users can have fun exploring around. I designed a lawn for large animals like sheep and horses and designed more specific scenarios for small animals like dogs, turkeys, birds, and pigs. I also placed some vertically moving clouds on the lawn for users to wait and catch. Each cloud represents one empty beat. When clouds are at the high point, users are not able to reach them; only when clouds are at the lowest point, users can catch them.


I created UI to let users have more control in the virtual world. For example, the music panel gives information regarding the composition, such as a metronome, tempo, and volume.

Interaction Design

I am also responsible for the interaction design of the game. One important interaction is the position of the music panel. Check the right column to see the details.


In the first version, I attached the panel to the main camera and keep it stuck to the top corner. After testing with several players, I found the position was too high and it was hard for players to see the panel details. And then I attached it to the left controller. Only when users lift the left controller, they can see it. Otherwise, it is below the view and is invisible.

Version 1.0:

The panel and volume stick to the top corner in world screen view


> Hard to see and interact

> Block the environment and break immersion

Version 2.0:

Reflection

What if I have more time…

> Better tutorial on the landing stage


When we displayed the game in public at the showcase, many players didn’t get the game rules at first and required an explanation. They all tended the skip the how-to-play session and enter the scene directly. One way they solve the problem is to set the tutorial as the first scene and make it unskippable. Players have to finish the learning task before starting the game.

> Add animation to animals


I think the environment can be more engaging and vivid if the animal can move or act naturally. For example, pigs eat their apples, birds fly freely on the farm, and horses run around the farm. Some animals can be static while others move fast. In this way, users need to chase animals to get some specific sound, which can make the experience more exciting.
